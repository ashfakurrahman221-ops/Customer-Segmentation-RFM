# Customer-Segmentation-RFM
Customer Segmentation using RFM analysis and KMeans Clustering
## Dataset
This project uses the [Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail) 
from the UCI Machine Learning Repository (also available on 
[Kaggle](https://www.kaggle.com/datasets/rahmanashfakur/onlineretail)).

Citation: Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. 
https://doi.org/10.24432/C5BW33

## Project Overview
Customer segmentation using RFM (Recency, Frequency, Monetary) analysis and KMeans clustering. 
Customers are grouped into Diamond, Gold, and Silver segments based on purchasing behavior.
